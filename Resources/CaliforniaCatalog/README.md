# California community source-photo archive

This is a curated archive of 100 real, dated California iNaturalist observations, one unique species and source photo per entry. These are source photographs, not user observations or AI-generated companions. No requests were made to an AI service. No credentials, keys, or paid services were used.

`catalog.json` is the reusable manifest; `photos/` contains unmodified official iNaturalist large photo derivatives (normally no more than 1024 pixels on the longer edge). `selection.json` preserves reviewed observation IDs for repeatable collection. All IDs are stable UUIDv5 values derived from the source observation URL.

## Provenance and licensing

Only each observation's actual photos with `photo.license_code` equal to `cc0` or `cc-by` were accepted. An observation's license or a taxon's default photo license was never substituted. All copyright notices supplied by the API are preserved in `sourceAttribution`; observer and photographer are separate fields. The photographer name is parsed from the API's credit, with the source observer as a fallback for CC0 uploads lacking a named copyright holder. `photographerNameSource` identifies that case.

Each image row below links its original observation, photo page, and license. Display the credit and license link whenever showing or adapting a photograph. If an AI companion is later created, retain the source credit, link, and license and label the generated derivative separately. The downloaded sources have not been edited.

iNaturalist [license documentation](https://help.inaturalist.org/en/support/solutions/articles/151000173511) links CC BY to version 4.0 and CC0 to version 1.0. Its [license module](https://github.com/inaturalist/inaturalist/blob/main/app/models/shared/license_module.rb) specifies CC_VERSION 4.0. The [API documentation](https://api.inaturalist.org/v1/docs/) describes the public observation endpoint. California place ID 14 was checked against [`/v1/places/14`](https://api.inaturalist.org/v1/places/14).

## Location and dates

Every accepted observation belongs to California place 14 and is research grade. Private, obscured, captive, extinct, and threatened records were excluded, including records with non-open taxon geoprivacy. Source latitude/longitude are the API's unmodified public coordinates; display latitude/longitude are rounded to 0.01 degree and have a conservative minimum accuracy value of 1000 m. Source public accuracy is separately retained. These historic points do not claim live animal presence. Region labels describe collection query areas and overlap; `locality` is the original source locality label.

`observedOn` preserves the source calendar date; observations after 2026-10-16 are excluded. `observedAt` preserves the actual timestamp where available. A date-only record has `hasSourceObservationTime=false`; its timestamp is a transport placeholder only, and the UI must show `observedOn` without claiming an exact time.

## Reuse

The checked-in manifest, selection and audit preserve the curated source IDs. This submission snapshot includes the licensed photographs and their credits; the development-only network collection script and caches are not included. Keep the per-photo attribution and license when redisplaying these files.
