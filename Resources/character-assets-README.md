# Offline nature companions

These transparent stickers are separate from the historical observation photographs. No source photograph was changed, traced, repainted, or replaced.

The app chooses a sticker using a fixed scientific-name mapping in `SpeciesCharacterCatalog.swift`. All 100 California archive records are covered. Nine records have a manually tailored, stylized plant character. All other records explicitly use a shared type companion. A type companion does not claim species-level markings or botanical accuracy. The real photo and source observation remain the identification evidence.

Nature Relay added transparent padding and white sticker edges. Selected stock plants received a simple face, and selected birds, butterflies, and the bear received broad color-family variants. Those variants remain type companions and do not claim to reproduce an actual species’ markings. The original Nature Relay plant/canine/limpet vectors are dedicated to CC0 1.0. Two plant designs retain Twemoji’s stem/leaf component and remain credited as CC BY 4.0 adaptations.

This is stock art and manually authored vector art. It was not generated by an AI image service. No paid assets or protected game characters are included.

## Files and rebuilding

`Adaptations/` contains the reviewable SVG vector sources; the matching root PNG files are 512 × 512 transparent images used by UIKit. The bundled `character-asset-credits.json` duplicates `Resources/character-asset-credits.json` so attribution travels with the asset folder.

`build_assets.py` writes the adapted SVG files. Rasterize them with Sharp at 512 × 512. `build_catalog.py` checks the source catalog and writes the Swift mapping and both credit manifests. It fails if a scientific name is missing.

`isSpeciesSpecific` means a plant companion was manually tailored to the listed species. It is an illustration, not a validated identification guide. It must never be presented as a result of image recognition.
